# Claude Desktop CN + CCSwitch 一键安装器

面向 Windows 10/11 的便携式安装辅助脚本，可下载并解压 Claude Desktop CN 与 CCSwitch。CCSwitch 可用于配置你自己拥有的模型服务凭据；本项目不会代替你提供 API Key。

> **安全提示：** 运行前请阅读下方的“下载来源与安全边界”。当前脚本通过第三方 GitHub 镜像尝试下载，并主要用文件大小判断下载是否完整，**没有对所有下载文件做 SHA-256 固定值校验或逐一验证代码签名**。HTTPS 不等于下载内容一定可信。不要在存有敏感资料或高权限账号的环境中盲目运行脚本。

## 功能

- 可选安装目录，默认使用脚本所在目录。
- 下载并解压指定版本的 Claude Desktop CN、CCSwitch 和 7-Zip 命令行工具。
- 生成启动脚本、卸载脚本和桌面快捷方式。
- 支持重复运行时跳过检测到已存在的部分组件。

## 下载来源与版本

目前 `install.ps1` 中写死的组件来源与版本如下；它们是脚本当前配置，不代表始终是上游最新版本。

| 组件 | 仓库/来源 | 当前脚本指定版本 |
|---|---|---|
| Claude Desktop CN | [Qiao-920/claude-desktop-cn](https://github.com/Qiao-920/claude-desktop-cn) | `v1.6.30` |
| CCSwitch | [farion1231/CCSwitch](https://github.com/farion1231/CCSwitch) | `v3.15.0` |
| 7-Zip 命令行包 | [7-zip.org](https://www.7-zip.org/) | 脚本 URL 指向 `7za920.zip` |

脚本会尝试多个 GitHub 下载代理，在可用时提高下载成功率。代理会参与传输链路，因此对于需要强供应链保障的环境，建议从上游官方发布页手动下载、验证后再使用，而不是依赖镜像自动选择。

## 使用方法

1. 从 GitHub 获取本仓库，并先阅读 `install.ps1`。
2. 在 PowerShell 中检查脚本内的下载 URL、版本和安装/清理路径是否符合预期。
3. 双击 `一键安装.bat` 启动脚本，或在 PowerShell 中手动运行 `install.ps1`。
4. 根据提示选择安装目录。首次运行需要网络连接。
5. 检查下载内容与安装目录后，再运行生成的 `launch.bat`。

如 Windows 的执行策略阻止脚本运行，不要为了省事而长期降低系统策略；先阅读脚本并确认来源，再按自己的设备管理规则决定是否执行。

## 安装与清理行为

- 下载文件暂存于系统临时目录中的 `ClaudeUSB_dl`。
- 安装目录下会创建 `CCSwitch`、`ClaudeDesktop` 等目录，以及 `launch.bat`、`uninstall.bat`。
- 卸载脚本会结束若干指定进程、删除安装目录中的对应组件和生成的脚本，并尝试删除桌面快捷方式与下载缓存。运行前请确认这些路径没有放入自己需要保留的文件。
- 脚本不是包管理器，也不是完全可复现的安装流程；不同 Windows 版本、上游发行包结构和网络镜像状态都可能影响结果。

- 不要把 API Key 写入公开仓库、Issue、日志或截图；如发生泄露，应立即撤销对应密钥。
- 不要将真实密钥、代理认证信息或敏感环境变量粘贴到公开问题中。

## 下载前的安全检查清单

- 在运行前查看脚本中的下载地址、固定版本和删除操作。
- 尽量使用上游官方发布页；在上游提供校验和或数字签名时，先核验再使用。
- 对下载文件进行本机安全扫描，并以普通用户权限进行首次验证。
- 先备份安装目录；如果目录中已有个人文件，不要直接选择覆盖安装。
- 如果你无法确认下载文件的来源和完整性，请不要继续运行。

## 系统要求

- Windows 10/11（64 位；具体兼容性以各上游组件为准）
- 首次下载时需要网络连接
- 使用收费模型服务时，可能需要自行注册并配置相应 API Key
